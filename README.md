# Yash Jewellers | Royal Indian High Jewellery House

> **विरासत एवं विश्वास · Kanpur & Delhi Bullion Benchmark · Estd. 1975**  
> Exquisite 100% BIS Hallmarked Gold, Uncut Kundan-Polki, 22K Temple Heirlooms & Certified Natural Diamonds.

---

## ✨ Features

- **Royal Heritage Theme**: Deep Burgundy (`#270611`), Royal Maroon (`#6B0E2A`), Antique Gold (`#C5A059`), Champagne (`#F3E8D0`), and Ivory (`#FAF7F2`) luxury aesthetic.
- **Real-Time Bullion Trading Desk**: Live bullion rates indexed to Kanpur & Delhi spot benchmarks, conforming to Indian Customs Duty (6%) and GST (3%).
- **Interactive Ornament Price Estimator**: Instant estimation calculator for 24K, 22K, 18K gold and 999 silver with making charges and GST transparency.
- **High Jewellery Catalogue**: Filterable by bridal suites, ladies rings, gents signets, bangles, and sacred mangalsutras.
- **Quick View & WhatsApp Concierge**: Interactive modal with gross weight, hallmark ID, and 1-click WhatsApp inquiry.
- **VIP Atelier Booking**: Private bridal viewing and in-store lounge scheduler.
- **Mobile Floating Luxury Dock**: Bottom quick dock for live rates, call, and WhatsApp.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Production Build
```bash
npm run build
npm start
```
